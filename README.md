# Music Notation Studio

一个面向个人钢琴练习的工具，以 iPad 为主要使用设备，通过蓝牙 MIDI 接收电钢琴输入，提供识谱练习和节拍跟弹。

## 项目目的

让使用者坐到电钢琴前，就能打开工具并开始练习。第一阶段验证工具能否帮助使用者识别谱面音高、找到对应琴键，并逐步跟上节拍。

本项目从原 Music Notation Studio 重新开始。旧项目积累了输入、音频、谱面和练习能力，但主要面向电脑使用，功能逐渐扩展到乐谱编辑，尚未满足日常练琴的需要。新版围绕实际练习流程整体重新设计并从零实现，仅参考旧项目的解决思路与验证经验，不复用旧代码。

## 使用环境

- 部署：iStoreOS 设备，作为日常可访问的网页服务。
- 主要终端：iPad，优先设计横屏体验。
- 其他终端：iPhone 横屏；已完成多尺寸浏览器布局检查，真实设备仍待验收。
- 连接：电钢琴蓝牙 MIDI → Safari + Beacio → 练习工具。
- 用户已在其他上下文验证 Safari + Beacio 可以读取蓝牙输入；实际设备、系统与插件版本尚待补充记录。

## 第一阶段

1. 识谱练习：不限速度，弹对目标并松键后推进。
2. 节拍跟弹：谱面按 BPM 推进，反馈音高匹配与节拍表现。
3. 基础流程：打开工具 → 连接电钢琴 → 配置练习 → 开始弹奏 → 查看反馈 → 重练。

课程体系与具体曲目后续再考虑。当前不建设后端数据库，也不以完整乐谱编辑器为目标。

阶段一已完成统一乐谱模型、校验、JSON 读写与单音适配。阶段二已增加基础谱面预览，可查看和弦、时值、休止符与大谱表。接下来完善通用练习引擎，再接入更自由的出题和手动按谱录入。阶段顺序与完成条件见 [开发路线](ROADMAP.md)。

## 当前功能

| 模块 | 用途 |
|---|---|
| 进阶课程 | 按顺序打开课节，查看目标和练习提示 |
| 专项训练 | 按识谱、节奏、和弦、双手配合选练，或使用可配置的随机出题 |
| 钢琴曲库 | 按曲目打开乐谱，试听、识谱或跟弹 |
| 我的乐谱 | 新建、导入和编辑 v1 乐谱 JSON，在当前浏览器保存后直接练习 |

横屏主页为两行两列。二级窗口只用于选内容，音域、策略和速度等出题参数在进入随机练习后单独调整。谱面右上角是音名开关，进度和主操作在卡片下方。

**识谱**采用自由速度，弹对并松键后推进。**跟弹**采用固定速度，谱面从前置空白小节开始滚过固定判定线。随机单音练习的谱号固定，完整乐谱的谱号随谱移动。完整乐谱支持和弦、双声部、混合时值和休止。

主页底部的「谱例预览」用于验证记谱效果。完整谱面可静音播放游标或试听，也可以按声部浏览。输入支持蓝牙 MIDI、系统 MIDI、电脑键盘和触控。蓝牙面板可让已连接的电钢琴试奏中央 C。

## 开发与验证

技术栈：React、TypeScript、Vite、原生 CSS、SVG、Lucide 图标；Vitest 验证核心逻辑，Playwright 验证浏览器交互与布局。

建议使用 Node.js 24。首次安装依赖后启动：

```bash
npm ci
npm run dev
```

开发与构建预览默认监听 `0.0.0.0:8120`，端口占用时直接报错。生成本地证书后自动使用 HTTPS；未生成时使用 HTTP。仅需本机预览时可使用 `npm run dev -- --host 127.0.0.1`。

当前已配置电脑局域网 HTTPS：<https://192.168.31.186:8120/>，尚非 iStoreOS 部署。iPad／iPhone 需安装并完全信任通用本地 CA，再启用 Beacio 网站权限。证书生成、下载和信任步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

```bash
npm run build
npm run lint
npm test
npx playwright install chromium
npm run test:browser
```

已安装 Chrome 时，也可设置环境变量 `PLAYWRIGHT_CHANNEL=chrome` 执行浏览器测试。PowerShell 示例：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm run test:browser
```

`npm run build` 生成 `dist/`，后续可交由 iStoreOS 上的静态 Web 服务托管；具体服务配置与 HTTPS 方式待确定。应用无后端和数据库，运行不需要外部字体或 CDN。

当前验证结果：构建、Lint、29 项逻辑测试及 15 项 Chrome 浏览器测试通过。横屏尺寸覆盖 1024×768、1180×820、844×390、667×375、568×320；覆盖弹窗、键盘／触控输入、识谱动画、减少动态效果、音名开关与设置恢复、竖屏暂停和跟弹结算。上述结果不代表已经完成真实 iOS 或蓝牙硬件验收。
